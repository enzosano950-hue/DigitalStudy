#  DigitalStudy

##  Sobre o Projeto

O **DigitalStudy** é um protótipo de plataforma educacional feita como um projeto escolar desenvolvido com **HTML, CSS e JavaScript**, criado com o objetivo de facilitar a organização da rotina de estudos e melhorar a comunicação entre alunos e professores.

O sistema simula um ambiente virtual de aprendizagem, oferecendo funcionalidades como autenticação de usuários, gerenciamento de atividades, área de conversas e interface intuitiva para acompanhamento das tarefas acadêmicas.

Durante o desenvolvimento foram aplicados conceitos de desenvolvimento web, estruturação de páginas, organização de arquivos, criação de interfaces responsivas e manipulação de elementos da página.

---

##  Funcionalidades

* ✅ Sistema de login
* ✅ Página inicial da plataforma
* ✅ Interface organizada para navegação
* ✅ Área de atividades
* ✅ Visualização de atividades pendentes
* ✅ Sistema de conversas (chat)
* ✅ Perfil de usuário
* ✅ Navegação entre diferentes módulos da aplicação
* ✅ Interface moderna desenvolvida com HTML e CSS

---

##  Objetivo

O objetivo do projeto foi desenvolver um protótipo funcional de uma plataforma de estudos utilizando apenas tecnologias fundamentais da web, simulando recursos encontrados em ambientes virtuais de aprendizagem.

Além da parte visual, o projeto teve como foco praticar organização de aplicações, desenvolvimento de interfaces, experiência do usuário e estruturação de páginas web.

---

##  Conceitos aplicados

Durante o desenvolvimento foram utilizados diversos conceitos importantes, entre eles:

* Estruturação semântica com HTML5

* Organização modular de arquivos
* Navegação entre páginas
* Responsividade
